# CASHFLOW 101 - Jogo de Educação Financeira

Um jogo de tabuleiro educacional em português brasileiro baseado no CASHFLOW 101, criado para ensinar conceitos de educação financeira, investimentos e gestão de dinheiro.

## 🎮 Sobre o Jogo

CASHFLOW 101 é um jogo educacional que simula a vida financeira real, ensinando jogadores sobre:
- Gestão de fluxo de caixa
- Investimentos em ações e imóveis
- Gerenciamento de ativos e passivos
- Criação de renda passiva
- Saída da "Corrida dos Ratos" para a "Pista Rápida"

## 🚀 Como Jogar

1. **Abra o jogo**: Abra o arquivo `index.html` em qualquer navegador web moderno
2. **Configure os jogadores**: Selecione de 1 a 6 jogadores
3. **Escolha as profissões**: Cada jogador seleciona uma profissão (Médico, Engenheiro, Caminhoneiro, Secretária, Professor, Mecânico)
4. **Jogue**: 
   - Lance os dados para mover seu token
   - Gerencie suas finanças
   - Compre ativos para gerar renda passiva
   - Saia da Corrida dos Ratos quando sua renda passiva for maior que suas despesas!

## 🎯 Objetivo do Jogo

**Objetivo Principal**: Sair da "Corrida dos Ratos" (Rat Race) para a "Pista Rápida" (Fast Track) aumentando sua renda passiva até que ela supere suas despesas totais.

**Vitória**: O primeiro jogador que alcançar R$ 50.000 de renda passiva na Pista Rápida vence!

## 🎲 Mecânicas do Jogo

### Profissões Disponíveis
1. **Médico**: Alto salário, altas despesas
2. **Engenheiro**: Salário médio-alto, despesas moderadas
3. **Caminhoneiro**: Salário baixo, baixas despesas
4. **Secretária**: Salário baixo, baixas despesas
5. **Professor**: Salário médio-baixo, despesas moderadas
6. **Mecânico**: Salário baixo, baixas despesas

### Tipos de Investimentos
- **Ações**: Compre ações e venda quando o preço subir
- **Imóveis**: Casas, duplex e condomínios que geram aluguel
- **Negócios**: Franquias e empreendimentos com fluxo de caixa positivo

### Ficha Financeira
Cada jogador possui:
- **Renda**: Salário + Renda Passiva
- **Despesas**: Impostos, Hipoteca, Empréstimos, Cartões de Crédito, etc.
- **Fluxo de Caixa**: Renda Total - Despesas Totais
- **Dinheiro em Caixa**: Recursos disponíveis para investir
